## 默认开关与运行边界

以下是仓库配置默认值，不是对当前部署环境的读取结果；本次整理未读取本机 `.env*` 的凭据或实际开关。

| 配置项 | 默认 | 额外条件 |
| --- | --- | --- |
| `SEMANTIC_CATALOG_ENABLED` | `false` | 开启时校验已批准 reporting schema |
| `CONTROLLED_SQL_ENABLED` | `false` | 依赖语义目录；保留固定工具优先和所有来源门禁 |
| `APPROVED_QUERY_MEMORY_ENABLED` | `false` | 独立审核主体与审核 DSN |
| `ISOLATED_ANALYSIS_ENABLED` | `false` | 仅消费当前仍获授权的数据集 Artifact |
| `INVENTORY_MONITOR_ENABLED` | `false` | 独立监控身份、版本化策略和逐层已核验来源 |
| `SYCM_MANUAL_IMPORT_ENABLED` | `false` | 迁移、授权店铺映射和覆盖窗口满足要求 |
| `PARTIAL_ANSWERS_ENABLED` | `false` | 仅适用于已批准的部分答案形态 |

持续有效的约束：

- 拼多多永久不接入；仅保留拒绝/排除边界，不恢复旧计划中“等待授权”的建议。
- 缺失、未知、未认证不等于零；支付、出库、手工导出口径不互换；期间收支差额和参考毛利不冒充净利润。
- 不因读到命令就执行真实模型、真实平台 API、生产/预发布数据库操作、同步、迁移、部署、备份恢复或调度变更。需要当前任务明确授权。
- 正常数据库回归使用独立合成沙箱 `bi_agent_eval_test`，配置入口为仓库根 `.env.evaluation`；默认候选端口 55439，只绑定回环。既有 `bi_agent_test` 承载过真实导入/同步数据，不能因名字含 `_test` 就 seed/reset。
- SQL 文件最高编号为 `033`；编号有缺口，按 `backend/sql/` 实际文件顺序迁移，不补造缺号。测试沙箱初始化由现有 bootstrap 负责。
- 保护 `.cloudflared.*`、`.streamlit.*`、`.tools/`、`taoxi-probe-status.py`、`可参考/`、`.worktrees/`、凭据及用户 WIP；本轮整理不移动原始导出表格或运行日志。
