# 五分钟演示与面试讲解

本演示使用 `backend/tests/test_db.py` 的合成数据：2026-09-01 至 09-07 支付金额 1000 元，退款发生额 100 元，期间收支差 900 元。它只用于验证功能和口径，不代表真实店铺业绩。当前能力边界、验证证据与未执行的外部验证见[项目状态](PROJECT_STATUS.md)。

## 演示步骤

1. 按 [运行手册](runbook.md) 启动 FastAPI 与 Vite，打开 `http://127.0.0.1:5175`。
2. 新建对话，问“最近7天支付金额如何？”。助手通过 `query_business` 返回脱敏聚合结果和覆盖范围。
3. 继续问“那上个月呢？”。会话保留店铺和指标，但覆盖不足时返回缺数据，不能把局部日期当整月。
4. 问“9月1日至7日退款发生多少？”。结果为 100 元，包含跨期退款，不把它称为利润。
5. 问“假设下月销售10万元，推广费率12%”。助手通过 `evaluate_promotion` 返回 12000 元上限，并标注该数值来自用户假设。
6. 问“最近7天实际推广费率和 ROAS”。助手说明快麦数据尚未证实推广实耗，不能计算。

## 模块边界

| 模块 | 输入 | 输出 | 责任 |
| --- | --- | --- | --- |
| React 工作台 | 会话与 SSE | 聊天、状态、附件 | 会话操作和展示，不存密钥 |
| FastAPI | 同源 HTTP 请求 | CRUD、SSE | 身份、Origin、会话并发边界 |
| Agent | 用户问题、历史 | 六个受限工具调用（一次完整业务请求通常一次业务 Tool） | 路由、参数补全、澄清、匿名映射、预算与降级 |
| 指标 | 参数化查询 | Decimal 聚合结果 | 覆盖、权限、金额和指标口径 |
| 同步 | 快麦分页响应 | 经营事实和水位 | 幂等、回滚、拆合单与退款处理 |

可用 provider 由 `LLM_PROVIDER=qwen|deepseek` 在 API 启动时确定。离线验收只验证协议和业务结果，不代表真实模型已验收；各工作流的真实可用边界见[项目状态](PROJECT_STATUS.md)。演示上架价复核与库存预警时要说清：真实部署里只会报「来源尚未取证」，不报价格差异也不报库存安全，不得拿合成用例的通过冒充线上可用。

## 五分钟演示步骤（四工作流）

1. 商品运营：「直钉枪在所有店铺近七天卖得怎么样？」——一次工具调用拿到跨店表与七日趋势；商品文字命中多个候选时要反问，不代选。
2. 平台对比：「五个平台近七天哪个卖得好？」——表格与柱图逐项相等；缺数的平台只给原因，不给 0 柱子，合计与排名只覆盖同口径分组。
3. 单店下钻：「比较一下抖音各店铺的支付金额」——点一个平台只发一句新请求，窗口与口径沿用本轮，范围由服务端重新展开授权。
4. 价格复核：「直钉枪的标价是 19.90，都对不对？」——目标价只认本轮这句；下一句不给价就只反问不沿用。当前无真实渠道在售价来源，它会如实回答「来源尚未取证」。
5. 库存预警：「看一下全商品总库存和店铺预警」——实物与渠道可售两行各说各的：三店共仓 100 件仍只有 100，缺阈值是「未配置」而不是「安全」。当前无真实库存来源，同样只报「来源尚未取证」。

## 合成评测套件演示路径（2026-10-24 起，离线可复跑）

不调用真实模型、不碰真实数据：在独立合成沙箱上，用脚本模型驱动工具调用，
演示五条经营者核心路径（场景定义与机器期望见
`backend/tests/evaluation/cases/operator_core.jsonl`，当前验证状态见
[项目状态](PROJECT_STATUS.md)）：

```bash
cd backend
uv run --locked --env-file ../.env.evaluation python -m tests.evaluation.runner \
  --mode offline --suite tests/evaluation/cases/operator_core.jsonl \
  --repeat 1 --output ../.tmp/evaluation/demo
```

| 路径 | 场景 | 看点 |
| --- | --- | --- |
| 平台可比结果 | oc-017 | 支付口径只认已认证平台；未认证格 missing 不补零 |
| 精确店铺下钻 | oc-024 | 换店后口径与披露随之切换，不继承上一轮 |
| 部分答案披露 | oc-012 | 已覆盖段出数 + 缺口起点 + 未核验披露 |
| 毛利确认 | oc-004 | 缺确认/换平台重试都 needs_input，显式确认才执行 |
| 上传后原题重查 | oc-028/029 | 越窗仍缺（上传成功≠覆盖成功）；同窗重查不重复计数 |

离线报告固定标注「脚本模型下的协议与业务回归，不衡量自然语言理解」；
它不证明真实模型准确率，也不构成任何平台真实来源就绪的证据。
