# 隔离分析 Agent 本地开发例外

日期：2026-09-16

状态：**仅授权本地开发；不构成发布门禁通过**

## 决定

项目所有者在语义目录、受控 SQL 探索与 approved 查询学习记忆均已完成本地实现、独立审查、父级回归和日期化验收后，明确要求继续执行剩余计划，并确认当前具有真实快麦 API 配置。因此，在 Task 11 统一发布门禁第 4–7 项尚未完成时，允许本地实施 `2026-09-14-isolated-analysis-agent.md` 的 Task 1–6。

该决定只解除隔离分析 Agent 的本地实施限制，不修改总设计中的生产发布标准。已成功执行的真实快麦只读探针只证明当前凭据与相应接口可用，不构成真实 provider、生产部署、恢复演练或一周用户试用证据，也不得把任何未执行验证记为通过。

## 允许范围

- 仅实施隔离分析 Agent 计划 Task 1–6；
- `ISOLATED_ANALYSIS_ENABLED=false` 保持默认关闭；
- 只使用本机 `*_test` 数据库、stub 模型和离线测试；
- 允许编写 `022_isolated_analysis_artifacts.sql`，并仅在本机 `*_test` 数据库顺序执行和幂等重放；
- 分析运行只能接收已授权、不可变且版本精确匹配的 Artifact 值对象；不得直接访问数据库、文件、网络、同步代码或业务 Tool；
- 模型只可在空工具环境中总结服务端已验证 finding，并必须引用 `finding_ref`；无证据的因果或行动结论必须拒绝；
- 每个计划 Task 继续执行原生 `glm-5.3-flash:high` 子代理、fresh 独立审查、父级验证和单独提交；
- feature gate 关闭时，现有 Tool、数据库读取和用户可见行为必须保持不变；
- 允许继续执行经脱敏、只读的真实快麦来源探针，但不得把探针结果写入本机测试库以外的数据库。

## 仍然禁止

- 在生产或预发布流量中启用隔离分析 Agent；
- 把当前占位模型配置或 stub 调用写成真实 provider smoke / 26 题 live 通过；
- 生产/预发布数据库迁移、部署、OIDC、反向代理、SSE、计划任务、备份或恢复操作；
- 分析模块生成或执行 SQL、访问数据库/文件/网络、调用同步、价审、库存调整或通知 Tool；
- 读取、保存或传播 DSN、API 密钥、Token、真实业务主键、客户信息或未脱敏错误堆栈；
- PDD 连接器、来源、支付能力、凭据或 onboarding；
- 在本例外下启动持续库存通知。后者仍必须先取得日期化 `inventory-source-acceptance`，逐层证明来源登记、freshness policy、完整扫描凭据和生产对账。
