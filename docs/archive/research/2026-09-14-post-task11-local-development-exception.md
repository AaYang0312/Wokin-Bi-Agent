# Task 11 后置项目本地开发例外

日期：2026-09-14  
状态：**仅授权本地开发；不构成发布门禁通过**

## 决定

项目所有者在 Task 11 已完成离线结构化验收、四工作流测试和锁定环境回归后，明确选择“仅本地开发例外”：允许在统一发布门禁第 4–7 项尚未完成时，实施 `2026-09-14-semantic-catalog-and-schema-retrieval.md` 的 Task 1–5。

该决定只解除“不得写后置功能代码”的本地实施限制，不修改总设计中的生产发布标准，也不把未执行验证记为通过。

## 允许范围

- 仅实施语义目录与 Schema 检索计划；
- 所有功能位于默认关闭的 `SEMANTIC_CATALOG_ENABLED=false` 门禁之后；
- 只使用本机 `*_test` 数据库、stub 模型和离线测试；
- 允许在本机测试库执行只读 introspection；
- 每个计划 Task 继续执行独立审查、父级全量验证和单独提交；
- feature gate 关闭时，现有 Tool、数据库读取和用户可见行为必须保持不变。

## 仍然禁止

- 真实 provider smoke 或 26 题 live 验收；
- 生产/预发布数据库、迁移、来源同步、回填、对账、部署、OIDC、SSE、计划任务、备份或恢复操作；
- 真实上架价或库存来源就绪声明；
- PDD 连接器、来源、支付能力、凭据或 onboarding；
- 启用语义目录用于生产流量；
- 在本例外下开始受控 SQL、approved 查询记忆、隔离分析或持续库存通知。

## 未完成门禁

`2026-09-14-task-11-release-acceptance.md` 记录的统一发布门禁第 4–7 项仍为 open：

1. 获准真实 provider smoke 与 26 题 live；
2. 目标环境迁移、来源及能力核对；
3. 可信身份、Origin、SSE、同步、重核、脱敏日志、备份和真实恢复；
4. 一店一周试用与问题归档。

语义目录本地测试通过不得改变这些状态。任何生产启用或其他后置子项目的门禁例外都需要新的、明确的所有者决定。
